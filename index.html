Configuración de Datos

Los datos ingresados se insertarán directamente en tu script personalizado.

Vista Previa del Script

Cómo utilizar este script

1

Instala una extensión

Descarga Tampermonkey o Violentmonkey en tu navegador (Chrome, Firefox, Brave, Edge).

2

Copia o Descarga

Usa el botón Descargar .user.js o copia el código directamente al portapapeles.

3

Crea un nuevo Script

Abre la extensión en tu navegador, crea un nuevo Userscript y pega el contenido generado.

4

¡Listo para usar!

Ingresa a los sitios de visado/consulado de Francia y los datos se autocompletarán en segundos.
